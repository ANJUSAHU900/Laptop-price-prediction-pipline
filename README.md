# 💻 Laptop Data Analysis & EDA Project

An Exploratory Data Analysis (EDA) and data cleaning project focusing on laptop market specifications, pricing patterns, and brand-wise discount strategies.

---

## 📌 Project Overview
- Cleaned and preprocessed raw dataset columns, including string-to-numeric conversions for discount percentages.
- Performed descriptive analysis and category-wise aggregations using Pandas.
- Visualized brand-level average discounts with custom-styled Matplotlib bar charts.

---

## 🛠️ Tech Stack & Tools
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib
- **Platform:** Google Colab

---

## 🔍 Key Analysis Steps
1. **Data Cleaning:** Handled inconsistent text columns, stripped '%' symbols, and safely converted values to float types.
2. **Data Aggregation:** Grouped laptop data by brand to compute precise average discount metrics.
3. **Data Visualization:** Built informative bar plots with exact percentage annotations and rotated category labels for readability.
